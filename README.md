# Yingxuan Textile — Independent Website

Single-page static website for Yingxuan Textile (Suzhou) Co., Ltd. — a woven fabric manufacturer in Shengze, Suzhou, China.

## Quick Start

Open `index.html` in any browser — no build step, no server needed.

## Deployment

### Option 1: Cloudflare Pages (Recommended — Free)

1. Push this folder to a GitHub repository
2. Go to [Cloudflare Pages](https://pages.cloudflare.com/)
3. Connect your repo → deploy
4. Bind your custom domain (e.g. `yingxuantextile.com`)
5. Automatic HTTPS + global CDN

### Option 2: GitHub Pages (Free)

1. Push to a repo
2. Settings → Pages → Deploy from `main` branch, root folder
3. Access at `your-username.github.io/repo-name`

### Option 3: Any Static Host

Upload `index.html` + `images/` folder to any web server via FTP/SFTP.

## Adding Images

1. Put your product photos in the `images/` folder
2. Use the filenames listed in `images/README.md`
3. The site auto-detects matching filenames and displays real images
4. Placeholder cards show until images are added

## File Structure

```
yingxuan-website/
├── index.html          ← The entire site (inline CSS + JS)
├── images/
│   ├── README.md       ← Image requirements
│   └── *.jpg           ← Your product photos
└── README.md           ← This file
```
